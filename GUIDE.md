# Гайд по club-rating-bot

Для того, кто будет пользоваться ботом и потом захочется что-то в нём поправить руками (ну, руками ИИ).

---

## Часть 1. Как пользоваться ботом

### Если ты участник клуба

1. Открой бота в Telegram по его ссылке (`@юзернейм`), нажми **Start**.
2. Напиши своё имя. Всё, ты зарегистрирован.
3. Кнопка **«Моя карточка»** — что у тебя по лекциям (`✅` был, `❌` не был), какие места на мероприятиях, сколько очков и какое место в общем рейтинге.
4. Кнопка **«Рейтинг»** — весь клуб списком, сверху те, у кого больше очков. Листается кнопками `◀️` и `▶️`.

### Если ты админ

Админ — это тот, чей Telegram ID вписан в `ADMIN_IDS`. Узнать свой ID можно у бота `@userinfobot` (напиши ему что-нибудь, он пришлёт цифры).

У админа в меню появляется кнопка **«⚙ Админ-панель»**, а внутри:

- **Участники** — выбрать человека и отметить лекции. Нажатие на лекцию переключает `✅` / `❌`. Кнопкой «Указать место на мероприятии» ставится место, нажатие сразу сохраняет.
- **Лекции** — добавить новую или убрать ненужную (нажать на лекцию = удалить её).
- **Мероприятия** — то же самое.
- **Загрузить таблицу** — присылаешь боту файл Excel, он всё заносит и пересчитывает рейтинг.
- **Скачать таблицу** — бот пришлёт текущие данные одним файлом.

### Как считаются очки

За каждое мероприятие: 1 место — 3 очка, 2 место — 2, 3 место — 1, четвёртое и ниже — 0. Очки со всех мероприятий складываются. Больше сумма — выше в рейтинге. Лекции на очки не влияют, это отдельная галочка в карточке.

### Формат Excel для импорта

Файл `.xlsx` с двумя листами.

Лист **«Лекции»**: первая колонка называется `Участник`, дальше колонки с названиями лекций. В ячейке `✓`, `да` или `1` — был; `—`, `нет` или `0` — не был.

| Участник | Лекция 1 | Лекция 2 |
|----------|----------|----------|
| Иван     | ✓        | нет      |
| Мария    | да       | 1        |

Лист **«Места»**: колонки `Участник`, `Мероприятие`, `Место`.

| Участник | Мероприятие      | Место |
|----------|------------------|-------|
| Иван     | Кубок весны 2026 | 1     |
| Мария    | Кубок весны 2026 | 2     |

Люди, лекции и мероприятия из файла, которых ещё нет, создаются сами.

## Часть 2. Как менять код через ИИ

Смысл простой: есть инструмент, который видит файлы проекта и по твоей просьбе их правит. Это может быть opencode, Claude Code, Cursor или обычный ChatGPT с копипастой. Разница только в удобстве.

### Что поставить на комп

Чтобы собрать бота, нужны **Java 21** и **Maven**. Проверь в терминале:

```
java -version
mvn -v
```

Если пишет версии — всё есть. Если «не является командой» — поставь JDK 21 и Maven, потом вернись сюда.

### Как открыть проект в ИИ

Пример на opencode (его ставит тот, кто дал тебе проект, или гугли «opencode install»):

```
cd C:\Users\user\projects\club-rating-bot
opencode
```

В Cursor просто открой эту папку через **Open Folder**. Главное, чтобы инструмент видел папку `club-rating-bot`, а не отдельный файл.

### Как просить

Пиши обычными словами, как объясняешь другу. Хорошая просьба выглядит так:

> Поменяй очки за места: за 1 место 5, за 2 — 3, за 3 — 1. Потом собери проект.

Три правила, чтобы не мучиться:

1. **Одна правка за раз.** Не мешай десять задач в одну просьбу.
2. **Говори, что хочешь видеть**, а не как это кодить. «Хочу, чтобы в рейтинге было только топ-10» понятнее, чем «поменяй стрим в leaderboard».
3. **Проси пересобрать.** После правки говори: «Собери и проверь, что нет ошибок».

### Как собрать файл для хоста

Любая правка заканчивается сборкой. В той же папке выполни:

```
mvn clean package
```

Занимает пару минут. На выходе — `target\club-rating-bot-1.0.0.jar`. Именно этот файл уходит на сервер.

### Как залить обновление на сервер

1. Открой файл-менеджер сервера, папка `/home/container`.
2. Удали там старый `club-rating-bot-1.0.0.jar`.
3. Залей новый jar из `target\`.
4. Рядом должен лежать `config.properties` (его не трогай постоянно).
5. Перезапусти сервер.

База данных — это файл `club_rating.mv.db`, он создаётся сам рядом с ботом. Ничего дополнительно ставить не надо. Если кто-то поменяет `DB_URL` на строку с `mysql`, бот упадёт с «Connection refused» — верни строку про `h2`, она есть в `config.example.properties`.

## Часть 3. Где что лежит

Чтобы понимать, что просить у ИИ, полезно знать карту.

```
club-rating-bot/
├─ config.properties              ← токен, ID админов, база (НЕ выкладывай в интернет)
├─ config.example.properties      ← образец настроек, можно показывать
├─ pom.xml                        ← список библиотек и как собирается проект
└─ src/main/
   ├─ java/com/clubrating/
   │  ├─ App.java                 ← запуск: подключиться к базе и стартовать бота
   │  ├─ config/Config.java       ← как читаются настройки из файла
   │  ├─ bot/
   │  │  ├─ ClubBot.java          ← вся логика: команды, кнопки, импорт/экспорт. Чаще всего правят тут
   │  │  ├─ Ui.java               ← тексты, которые видит человек
   │  │  └─ Keyboards.java        ← сборка кнопок
   │  ├─ service/
   │  │  ├─ RatingService.java    ← очки и рейтинг
   │  │  └─ ExcelService.java     ← чтение и запись .xlsx
   │  ├─ repo/                    ← запросы к базе (участники, лекции, посещения, места)
   │  └─ model/                   ← простые классы-данные
   └─ resources/db/migration/
      └─ V1__init.sql             ← структура базы (таблицы)
```

Если просишь поменять текст в боте — это `Ui.java`. Если поведение кнопок — `ClubBot.java`. Если формулу рейтинга — `RatingService.java`. Скажи это ИИ, он сразу полезет куда надо.

## Часть 4. Примеры просьб для ИИ

- «Добавь в карточку участника строку: сколько всего мероприятий он посетил.»
- «В рейтинге показывай только первые 10 человек.»
- «Поменяй очки: за 1 место 5, за 2 — 3, за 3 — 1.»
- «В главном меню замени текст на такой: ...»
- «Добавь в админ-панель кнопку “Сбросить у всех лекции” с подтверждением.»
- «Сделай, чтобы в Excel места можно было писать словами “первое”, “второе”.»

После каждой — «собери `mvn package`». Потом залей jar на сервер.

## Часть 5. Если что-то сломалось

- **`BOT_TOKEN is not set`** — рядом с jar нет `config.properties`. Залей файл.
- **`Connection refused` про mysql** — в настройках оказалась строка MySQL вместо H2. Верни `DB_URL` с `h2`.
- **Бот молчит** — проверь, что jar и config лежат в одной папке и сервер перезапущен.
- **Красная ошибка при нажатии кнопки** — скопируй текст ошибки и отдай ИИ целиком, вместе со строкой, где что-то не так. Он поправит.

Не выкладывай никуда файл `config.properties` — в нём токен бота. Если токен утёк, зайди к `@BotFather` и сделай `/revoke`.
