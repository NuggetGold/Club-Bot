# Club Rating Bot

Telegram-бот для клуба: участники регистрируются по имени, смотрят свою карточку
(пройденные лекции и места на мероприятиях) и общий рейтинг. Админ редактирует
данные прямо в боте или загружает Excel-таблицу.

## Как считаются очки

За каждое мероприятие участник получает очки по занятому месту:

| Место | Очки |
|-------|------|
| 1     | 3    |
| 2     | 2    |
| 3     | 1    |
| 4 и ниже | 0 |

Очки суммируются по всем мероприятиям и задают позицию в рейтинге.
Посещение лекций на очки не влияет — это отдельная отметка в карточке.

## Стек

- Java 21
- [telegrambots](https://github.com/rubenlagus/TelegramBots) 6.9.7.1
- Встроенная БД H2 (файл рядом с ботом) + Flyway, пул HikariCP; опционально внешний MySQL
- Apache POI — импорт и экспорт XLSX
- Maven

## Запуск

1. База данных не нужна — используется встроенная H2, файл `club_rating.mv.db`
   создаётся рядом с ботом при первом запуске. Схему накатывает Flyway.
   (Можно переключиться на внешний MySQL, задав `DB_URL` в `config.properties`.)

2. Скопируйте `config.example.properties` в `config.properties` и заполните:

   | Ключ           | Что это                                                       |
   |----------------|---------------------------------------------------------------|
   | `BOT_TOKEN`    | токен от [@BotFather](https://t.me/BotFather)                  |
   | `BOT_USERNAME` | юзернейм бота без `@` (для ссылки на личку)                    |
   | `ADMIN_IDS`    | Telegram ID админов через запятую (узнать в [@userinfobot](https://t.me/userinfobot)) |
   | `DB_URL`       | JDBC-строка MySQL                                              |
   | `DB_USER`      | пользователь БД                                                |
   | `DB_PASSWORD`  | пароль БД                                                      |

   Любой ключ можно переопределить переменной окружения с тем же именем.

3. Соберите и запустите:

   ```
   mvn clean package
   java -jar target/club-rating-bot-1.0.0.jar
   ```

   В консоли появится `Club rating bot started. Username: @...`.

## Как пользоваться

- **Участник:** `/start` → имя → кнопка «👤 Моя карточка» (лекции и места) и
  «🏆 Рейтинг» (общий список с сортировкой по очкам).
- **Админ:** кнопка «⚙ Админ-панель» — участники, лекции, мероприятия,
  загрузка и выгрузка таблицы. В карточке участника нажатие на лекцию
  переключает ✅ был / ❌ не был, а на мероприятии — сразу сохраняет место.

## Формат Excel

Файл `.xlsx` с двумя листами.

**Лист «Лекции»** — колонка `Участник`, дальше колонки лекций. В ячейках
отметка посещения (`✓`, `да`, `1` — был; `—`, `нет`, `0` — не был).

| Участник | Лекция 1 | Лекция 2 |
|----------|----------|----------|
| Иван     | ✓        | нет      |
| Мария    | да       | 1        |

**Лист «Места»** — колонки `Участник`, `Мероприятие`, `Место`.

| Участник | Мероприятие       | Место |
|----------|-------------------|-------|
| Иван     | Кубок весны 2026  | 1     |
| Мария    | Кубок весны 2026  | 2     |

Участники, лекции и мероприятия, которых нет в базе, создаются автоматически.
Выгрузить текущее состояние можно кнопкой «⬇️ Скачать таблицу» — файл откроется
в том же формате для повторного импорта.

## Ограничения

- Импорт выполняется построчно и не обёрнут в одну транзакцию: при сбое
  посередине часть данных может уже попасть в базу. Проверяйте файл перед
  загрузкой.
- Удаление лекции или мероприятия каскадно удаляет связанные отметки и места.
- Файл импорта — не больше 10 МБ, регистрация участника доступна только
  боту в личных сообщениях.
